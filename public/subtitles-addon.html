Magyar feliratok

Először tölts fel feliratot (IMDB ID + .srt/.vtt), majd telepítsd az addont – lejátszáskor megjelenik a felirat választóban.

1. Lépés

Felirat feltöltése

nCore kommentekből letöltött .srt vagy .vtt feltöltése IMDB ID alapján. Egy filmhez/sorozathoz több felirat is feltölthető (pl. magyar, angol).

↑ Feliratok feltöltése (IMDB ID + .srt/.vtt)
2. Lépés

Addon telepítése

A feltöltött feliratok az addonon keresztül érkeznek Stremioba. Telepítsd az addont, majd lejátszáskor válaszd ki a feliratot.

Telepítés Stremioval
Telepítési lépések
  1. Először tölts fel feliratot a Feliratok feltöltése oldalon (IMDB ID + .srt fájl)
  2. Stremio → Addons → "+ Add addon" → illeszd be a fenti URL-t
  3. Lejátszáskor a felirat megjelenik a felirat választóban
